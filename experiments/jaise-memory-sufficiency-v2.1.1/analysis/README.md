# Post-hoc analyses over the published final-run logs

This folder contains the post-hoc statistical and functional-memory analyses
reported in the journal article (JAISE submission), together with frozen derived
outputs used to document and reproduce the reported results.

All analyses use only the published final-run logs in `../data/final_run/`.
They require no re-execution of the experiment and no GPU.

## Files

| File | Purpose | Input / origin |
| --- | --- | --- |
| `reproduce_statistics.py` | Reproduces the matched-block fixed-effects analysis for learner-trajectory dependence (Section 5.5), the token-composition models (Section 5.6), and the matched-block correlations. | `../data/final_run/episodes.jsonl.gz` |
| `mediation_analysis_v2.py` | Original exploratory token-composition mechanism analysis examining whether the C4--C0 time and dynamic-energy differences are statistically accounted for by token composition. Retained for provenance. | `../data/final_run/episodes.jsonl.gz` |
| `continuity_check_v2.py` | Functional-memory audit (Section 5.1): examines whether round-3 Teacher and Adapter outputs reuse prior-round-specific information under longitudinal memory configurations. | `../data/final_run/steps.jsonl.gz` |
| `rq4_block_fixed_effects.csv` | Frozen results of the matched-block configuration-by-trajectory interaction models reported in Section 5.5. | Generated by `reproduce_statistics.py` |
| `mechanism_block_fixed_effects.csv` | Frozen block-adjusted token-composition model results reported in Section 5.6. | Generated by `reproduce_statistics.py` |
| `mechanism_correlations_reproduced.csv` | Reproduced Pearson and Spearman matched-block correlations for the token-composition analysis. | Generated by `reproduce_statistics.py` |
| `mechanism_paired_c4_c0.csv` | Frozen matched-block dataset containing the 90 trajectory-by-repetition C4--C0 differences used in the mechanism analysis. | Derived from `../data/final_run/episodes.jsonl.gz` |

## Usage

From this directory:

```bash
cd analysis
python3 reproduce_statistics.py
```

The script first validates the experimental design before performing any
statistical analysis. The expected design is:

- 450 completed episodes;
- 6 learner trajectories;
- 15 matched repetitions per trajectory;
- 90 trajectory-by-repetition blocks;
- 5 memory configurations within every block.

The original mechanism and continuity scripts can also be run independently:

```bash
python3 mediation_analysis_v2.py
python3 continuity_check_v2.py
```

## Learner-trajectory dependence: Section 5.5

`reproduce_statistics.py` models learner-trajectory dependence using fixed
effects for the 90 trajectory-by-repetition matched blocks and tests the
memory-configuration-by-trajectory interaction.

The reproduced interaction tests are:

| Outcome | F | df | p |
| --- | ---: | ---: | ---: |
| Execution time | 2.926 | (20, 336) | 3.61 x 10^-5 |
| Dynamic GPU energy | 3.093 | (20, 336) | 1.31 x 10^-5 |
| Prompt tokens | 6.484 | (20, 336) | 6.85 x 10^-15 |
| Completion tokens | 3.221 | (20, 336) | 5.99 x 10^-6 |
| Total tokens | 4.350 | (20, 336) | 4.99 x 10^-9 |

These results are preserved in `rq4_block_fixed_effects.csv`.

They show statistically detectable heterogeneity in the operational effects of
memory configuration across learner trajectories. They do not imply that any
single memory configuration is universally superior.

## Token-composition mechanism analysis: Section 5.6

The block-adjusted models reproduce the principal C4--C0 contrasts:

- execution time: approximately -1.356 s;
- dynamic GPU energy: approximately -330.1 J.

After adding completion tokens as a covariate:

- the C4--C0 dynamic-energy coefficient is attenuated from approximately
  -330.1 J to -7.3 J (`p = 0.57`);
- the corresponding execution-time coefficient changes from approximately
  -1.356 s to +0.035 s (`p = 0.45`).

When prompt and completion tokens are included simultaneously, no residual
**overall** memory-configuration effect is statistically detectable:

- dynamic GPU energy: `F(4,354) = 1.90`, `p = 0.110`;
- execution time: `F(4,354) = 0.80`, `p = 0.527`.

The corresponding model outputs are preserved in
`mechanism_block_fixed_effects.csv`.

### Matched-block correlations

Across the 90 matched trajectory-by-repetition blocks, C4--C0 differences in
completion-token count are strongly associated with the corresponding
differences in dynamic GPU energy and execution time:

- completion-token difference vs dynamic GPU energy difference:
  Pearson `r = 0.983`, `p = 1.09 x 10^-66`;
- completion-token difference vs execution-time difference:
  Pearson `r = 0.988`, `p = 1.80 x 10^-72`;
- completion-token difference vs dynamic GPU energy difference:
  Spearman `rho = 0.982`;
- completion-token difference vs execution-time difference:
  Spearman `rho = 0.988`.

The independently reproduced values are stored in
`mechanism_correlations_reproduced.csv`. The previously frozen
`mechanism_correlations.csv` is retained for provenance.

### Matched C4--C0 dataset

`mechanism_paired_c4_c0.csv` contains one row for each of the 90 matched
trajectory-by-repetition blocks and includes differences in:

- completion-token count;
- prompt-token count;
- dynamic GPU energy;
- execution time.

Mean C4--C0 differences provide an additional sanity check:

- completion tokens: approximately -228.12;
- prompt tokens: approximately +97.86;
- dynamic GPU energy: approximately -330.13 J;
- execution time: approximately -1.356 s.

## Functional-memory audit: Section 5.1

`continuity_check_v2.py` evaluates whether information introduced in previous
rounds is subsequently reused.

Pooled across the six learner trajectories:

- prior-round lexical markers are detected in 21.1% of C0 episodes and
  78.9% of C4 episodes;
- the corresponding matched comparison gives McNemar discordant counts of
  53 versus 1 (`p = 6.1 x 10^-15`).

In the more discriminative subset, defined by a C0 marker base rate below 15%:

- marker presence is 5.0% under C0 and 88.3% under C4;
- the matched comparison gives McNemar discordant counts of 50 versus 0
  (`p = 1.8 x 10^-15`).

For this audit, lexical markers were defined from the learner trajectory
specifications in `../config/tasks_v2.yaml`. Two trajectories,
`overfitting_adaptation` and `llm_agents_study_plan`, contained markers that
could also arise naturally from the current topic under the stateless baseline.
The restriction to trajectories with a C0 marker prevalence below 15% is
therefore reported as a post-hoc sensitivity analysis.

  token-composition analysis;
- `mechanism_correlations.csv`: previously frozen correlation output retained
  for provenance.

## Methodological note

The token-composition analysis is exploratory and associative. The covariate
models and matched-block correlations examine whether generation length is
consistent with the observed operational differences. They are not interpreted
as formal causal mediation and do not establish that learner-state memory
directly causes lower energy consumption.

Likewise, the configuration-by-trajectory models assess heterogeneity in
operational effects across the six predefined learner trajectories. They do not
establish general superiority of one memory configuration beyond the evaluated
experimental workloads.

## Reproducibility scope

The files in this folder reproduce or preserve analyses conducted after the
experimental run. The original experimental observations remain frozen in
`../data/final_run/`.

No model weights, hidden reasoning traces, student data or additional
experimental observations are introduced by these analyses.
